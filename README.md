# Juice Bar & Smoothie Café

33 HTML pages; 93 files in one flat folder. Start at index.html.

Use a local web server or upload all files together to static hosting. The website uses local fonts and images. Keep every file together.

The two homepages end with their redesigned CTA panels, immediately before the footer. Banner photographs use contain fitting, short entrance animations and reduced-motion preferences. Header taglines and animation buttons have been removed.

Product photography remains consistent across listings and detail pages. Editorial photography is unique on the seven main pages; supporting pages use individually composed fruit illustrations to avoid repeating those photos.

Theme and text direction controls, menu filtering, ratings, saved offers and order-enquiry calculations work locally. Enquiry forms and newsletter requests do not send to a backend. Nutrition values remain pending verification.

Files: site.css contains the base styles; banner-buttons-update.css contains presentation layers and updates. runtime.js contains shared configuration and behaviour; page.js contains scoped page behaviours. order.js handles the dedicated enquiry flow.
